## 〇、一页纸总览

- **一句话核心**：**神即规则，弑神即改写规则。** 转职不是"学会技能"，而是把一条世界规则刻进自身的存在方式。

- **三层力量体系**（叙事与机制一一对应）：

| 层级  | 叙事本质       | 机制载体       | 可被剥夺？          | 死亡后     |
| --- | ---------- | ---------- | -------------- | ------- |
| 技艺层 | 人类锤炼的战斗技巧  | **卡牌**     | 可被烧毁 / 消耗 / 偷走 | 失去      |
| 权柄层 | 神遗落世间的权柄碎片 | **遗物**     | 本局持续，不进牌组      | 失去      |
| 规则层 | 你刻入灵魂的规则   | **转职专属能力** | **任何方式不可剥夺**   | 本局不死即永存 |

- **对称设计（最重要的独特理解）**：转职能力"不可剥夺"的另一面是**"不可退还"**——力量一旦刻入灵魂，你也无法再把它还给神。这就是"神性侵蚀"系统的根：**你无法被夺走力量，也无法拒绝力量带来的同化。**

- **局内结构**：选角（战士 / 猎人 / 法师）→ 三幕主题地图（每幕 6 层节点 + Boss）→ 第 1、2 幕 Boss 后两次转职（各二选一，共 4 个终职 / 角色）→ 第 3 幕结束后挑战本角色之神。

- **神战 = 毕业考试**：神会依次使用三幕地图的机制，半血后**复制玩家当前终职的专属能力（神级完全体）**。你要用从神那里学来的规则，打败规则本身。

- **三结局**：弑神（毁掉规则）/ 登神（承接规则，轮回闭环）/ 凡人（隐藏，以人之身承载而不被同化）。

- **开发范式**：垂直切片优先——**先把 1 个终职做透，再复制 12 次**；伤害管线与身份层是项目心脏，先建先测最后改。

### 成功标准的量化定义

| 指标 | 目标值 | 说明 |
|---|---|---|
| 单局时长 | 30~50 分钟 | 参考 STS 中位数 |
| 普通战斗 | 3~5 回合 | 超过即战斗过肉 |
| 精英战斗 | 5~8 回合 | |
| Boss 战 | 7~11 回合 | |
| 神战 | 15~25 回合（含四阶段） | |
| 一局完整流程 | 选角 → 三幕 → 神战 → 结局，零崩溃、零卡死 | 硬性门槛 |

## 一、世界观：三律界

### 1.1 神不是"住在天上的强者"，神是世界运行的规则本身

世界由三条根本法则维系，三神是这三条法则的**人格化**：

| 神      | 法则   | 它"是"什么            | 世间的表现                |
| ------ | ---- | ----------------- | -------------------- |
| **战神** | 争战之律 | 冲突本身：万物通过碰撞决出强弱   | 你挥刀会产生"力量"、弱者会被强者击倒 |
| **兽神** | 噬生之律 | 生存竞争本身：弱肉强食、生杀轮回  | 伤口会愈合也会腐烂、饥饿、繁衍、本能   |
| **法神** | 序秩之律 | 因果与代价本身：万物等价、言出法随 | 魔力流动、施法有代价、秩序与知识     |

神不需要军队、不需要降临、不需要被信仰。**你每一次呼吸、每一次挥拳，都在执行神制定的规则。** 造反的困难之处正在于此：你想用"力量"对抗神，而"力量"这个概念归神所有。

### 1.2 人的处境：人之限

人类的力量有一道看不见的天花板——**"人之限"**。无论如何苦修，锤炼到某个极限便再也无法寸进，因为规则的**最终解释权**在神手中。人能学会精妙的剑术（技艺），能捡到神遗落的奇迹（遗物），但永远无法**拥有规则本身**——除非理解它。

### 1.3 遗物：掉在人间的权柄

神在漫长岁月中会遗落"权柄碎片"：一缕未收回的战意、一节太古巨兽的脊骨、一句失效的律令。它们以**遗物**的形态散落在地图深处，捡到者可以借用规则的一角，但借用不等于拥有——人死了，遗物还在原地等下一个人。

### 1.4 核心反转：神在等你，神想死

三神表面上以人类的挣扎为乐、设下试炼与"选民"；但真相是：

> **规则是活的，而神是规则的囚徒。**
> 战神无法停止战争，兽神无法停止猎杀，法神无法停止计算。永恒地扮演一条规则，是一种没有尽头的苦役。
> 三幕地图的 Boss 不是狱卒，而是**考官**；神不断把权柄碎片"漏"给人间，是在筛选一个能把规则**完整理解**的人——只有这样的人，才能杀死规则本身，让神解脱。

所以最终战里，神会"喂招"、会欣慰、会在确认你真正掌握规则后欣然赴死。这给了"为什么 Boss 战后反而给你转职"一个顺理成章的解释：**每一次转职，都是神（通过其代行者）确认你有资格持有更多规则。**

### 1.5 三结局

| 结局         | 触发                         | 叙事                                             |
| ---------- | -------------------------- | ---------------------------------------------- |
| **弑神（毁律）** | 击败神后选择"毁掉权柄"              | 规则崩塌，世界再无超凡与奇迹，人类迎来自由但荒芜的平凡时代                  |
| **登神（承律）** | 神性 ≥ 90，或主动选择"穿上权柄"       | 你成为新的规则，随即理解了旧神为何求死——你开始等待下一个挑战者（轮回闭环，二周目钩子） |
| **凡人（超律）** | 隐藏：人性 ≥ 3 且神性 < 60 时出现第三选项 | 你以人之身承载规则而不被同化，向世界证明：人不需要神也能活                  |

> **本版约定**：凡人路线**仅实现结局判定**，暂不做机制补偿。凡人路线"奖励更薄、通关更难"是设计意图，其数值可行性见 §8.3。

## 二、转职系统（核心系统）

### 2.1 转职树结构

```
初始角色（无职业被动，只有初始牌组与初始遗物）
   │
   │ 第 1 幕 Boss 战后：一阶转职（二选一）
   ├──────────┐
 一阶A       一阶B
   │          │
   │ 第 2 幕 Boss 战后：二阶转职（在本分支下二选一）
   ├─┐        ├─┐
 终职1 终职2  终职3 终职4      ← 每个角色 4 个终职，三角色共 12 个
   │
   │ 第 3 幕：以终职身份走完最后一张地图，然后神战
```

- 转职**不可逆、不可重选、不可跨分支**（规则刻入即定型）。
- 第 3 幕不再有转职——你要以"最终的自己"面对神。

### 2.2 每次转职获得什么

1. **专属能力（规则刻印）**：不可剥夺，**改写一条基础规则或接通一条资源管线**——见 §2.3 的设计判据。
2. **职业核心牌**：从该职业卡池中**三选一，直接加入牌组**（转职面板完成）。

> **转职不增加最大生命。** 续航与仪式感改由职业机制本身承担（嗜血者击杀回血、壁垒靠格挡减伤），避免"转职 = 固定 +血"的无成本数值膨胀。

### 2.3 设计判据：什么才配叫"规则刻印"

**判据：每个专属能力必须改变"游戏怎么玩"，而不是"数字大一点"。** 具体满足以下之一：

- **改写一条基础规则**（例：壁垒把"格挡每回合清零"改为"留存 50%"）；
- **接通两条原本无关的资源管线**（例：盾猛把"获得格挡"接到"造成伤害"）；
- **反转一类负面事物的价值**（例：契约师让诅咒牌从垃圾变燃料）。

> **纯数值加成（"+3 力量"）不允许**作为转职能力——那是卡牌和遗物该干的事。
> 叙事理由：你是在"理解世界规则的一角"，理解改变的是世界本身，不是你的面板。

### 2.4 三角色转职总览

| 角色     | 一阶  | 二阶终职                | 一句话引擎               |
| ------ | --- | ------------------- | ------------------- |
| **战士** | 盾卫  | **壁垒** / **盾猛**     | 格挡跨回合留存 / 格挡即伤害     |
|        | 狂战  | **嗜血者** / **鏖战者**   | 以血换伤、击杀续航 / 出牌连击滚雪球 |
| **猎人** | 游侠  | **神射手** / **风行者**   | 印记延迟处决 / 首牌复制、高频连射  |
|        | 驯兽师 | **兽王** / **兽化者**    | 召唤兽群 / 人兽双形态切换      |
| **法师** | 元素师 | **风暴使者** / **奥术圣贤** | 双元素反应连锁 / 溢出法力蓄力巨炮  |
|        | 咒术师 | **死灵师** / **契约师**   | 消耗与死亡变魂能 / 诅咒牌变核弹   |

## 三、战士线（战神：争战之律）

**主题地图**：竞技场 → 战场 → 古战场（战争的三种形态：搏斗 → 战争 → 战争的遗骸）

**核心资源**：格挡、生命、怒气（一阶狂战引入，本回合叠加的临时攻击层数）

### 3.1 一阶・盾卫 —— "以身为墙"

- **一阶能力（建议）**：「持盾戒备」每回合获得的**第一张**格挡，额外 +3。
- 构筑方向：格挡牌、格挡成长、消耗战。

#### 终职：壁垒 —— "最坚固的墙永不倒塌"

- **专属能力（不可剥夺）**：**回合结束时，格挡不清除，保留 50%（向下取整）。**
- 钩子位置：`Creature.on_turn_end` 格挡清零规则改写（身份层，见 §10.2）。
- 玩法循环：前期叠甲 → 格挡滚到 Boss 打不动 → 用少量"盾击"类输出牌（按格挡量造成伤害）磨死对手。
- 协同牌：敏捷、每回合格挡、格挡转伤害、缓冲 / 免伤。
- **弱点（设计上必须存在）**：输出匮乏；**毒与生命流失无视格挡**——这是壁垒的天敌，神战中考验你是否准备了对策。

#### 终职：盾猛 —— "最好的防守，是正在进攻的防守"

- **专属能力（不可剥夺）**：**每当你实际获得格挡，立即对当前敌人造成等于本次格挡量 50% 的伤害。**
- **伤害类型（已确认：方案 A）**：盾猛伤害为 `NORMAL`，**吃力量 / 易伤**——高频小格挡触发多次，可走攻防一体流派。方案 B（独立 `SHIELD_BASH` 类型）废弃。
- 触发粒度：每次 `gain_block` 触发一次 → 3 张各 5 格挡的牌 = 触发 3 次（吃 3 次力量），天然引导**高频盾**构筑。
- 与壁垒的对照：**壁垒吃"时间"（跨回合累积），盾猛吃"空间"（资源转译）。**

### 3.2 一阶・狂战 —— "以伤换伤"

- **一阶能力（建议）**：「血勇」你每失去 2 点生命，获得 1 层**怒气**（每层 +1 攻击伤害，回合结束清零）。

#### 终职：嗜血者 —— "血债必须血偿"

- **专属能力（不可剥夺）**「血偿」：
  1. **怒气不再于回合结束清零**（改写怒气的衰减规则，跨回合保留）；
  2. 你每失去 **1** 点生命即获得 1 层怒气（一阶是每 2 点，效率翻倍）；
  3. 你每击杀一个敌人，回复 **6** 点生命。
- 玩法循环：用自残牌（对自己造成生命流失换取巨伤）+ 怒气叠加 → 血量越低、怒气越厚、伤害越恐怖，击杀回血续命。
- 风险：生命流失**无视格挡**，一次算错就是暴毙；需要热身，怕开局高压。

#### 终职：鏖战者 —— "攻势一旦开始，就不会停下"

- **专属能力（不可剥夺）**「怒涛」：本回合每打出一张攻击牌，获得 1 层**怒涛**（每层使攻击牌额外 +1 伤害，回合结束必定清零）。

> "≥6 张攻击后怒涛转抽牌（余韵）"**本期不做**（机制优先、数值后调），待 playtest 确认鏖战者是否缺续航后再决定是否补。

- 数学直觉：第 N 张攻击牌吃到 (N-1) 层加成，10 张攻击的总增伤为 0+1+…+9 = 45——配合 0 费攻击、抽牌、回旋，单回合指数膨胀。
- 风险：防御极薄；手牌事故或被眩晕 / 缴械即断连击。
- 与嗜血者的对照：**嗜血是纵向（血量经营、跨回合持续变强），鏖战是横向（单回合出牌数、节奏爆发）。**

## 四、猎人线（兽神：噬生之律）

**主题地图**：翠林猎场 → 大荒野 → 万兽冢（狩猎的三种形态：人猎兽 → 兽猎兽 → 猎杀的轮回）

**核心资源**：印记（标记猎物，不随回合衰减）、格挡（敏捷型）、召唤兽（一阶驯兽师引入，需友方单位系统）

> **猎人不做"闪避（概率 / 层数免伤）"独立资源**，用格挡 + 敏捷即可，避免新增系统成本；猎人初始牌组的「闪避」牌实为 1 费 5 格挡的普通防御牌（仅命名沿用）。

### 4.1 一阶・游侠 —— "猎物一旦被标记，只剩死亡时间问题"

- **一阶能力（建议）**：「猎手印记」你对敌人造成伤害时为其附加 1 层**印记**（持续至其死亡）；每层印记使其受到你的攻击 +1 伤害。

#### 终职：神射手 —— "我看见你生命的终点"

- **专属能力（不可剥夺）**「死亡印记」：
  1. 印记上限 10 层，**每层使目标受到你的伤害 +10%**（乘法修正，进入 `at_damage_receive`）；
  2. 印记满 10 层时**引爆**：造成目标**已损失生命值 40%** 的伤害（对 Boss / 精英封顶为其最大生命 15%），随后印记清零重新累积。
- 玩法循环：快速上印 → 磨血压血线 → 引爆处决 → 再上印。标准的"延迟斩杀"引擎。
- 协同牌：多段上印、群体上印、对低血目标增伤。

#### 终职：风行者 —— "快到箭还在飞，人已不在原地"

- **专属能力（不可剥夺）**「疾风连射」：
  1. **每回合打出的第一张攻击牌生效两次**（复制结算，含附着 / 印记两次）；
  2. 每回合额外抽 1 张牌。
- 玩法循环：高频 0~1 费攻击、多段伤害、抽牌回旋；与印记混搭时复制攻击 = 一次叠 2 层印记。
- 风险：复制每回合仅一次，大费牌复制收益高但卡手；身板脆。
- 与神射手的对照：**神射是单点延迟爆破，风行是回合内高频连射。**

### 4.2 一阶・驯兽师 —— "我不是一个人在狩猎"

- **一阶能力（建议）**：「伙伴」战斗开始时召唤 1 只**猎犬**（独立血量，每回合攻击；敌人可将其作为目标）。
- 系统需求：友方单位（allies）、敌人 AI 的目标选择（随机 / 嘲讽）。

#### 终职：兽王 —— "荒野以我的号令为群"

- **专属能力（不可剥夺）**「兽群领袖」：
  1. 战斗开始时召唤 **2 只强化猎犬**；
  2. 你的召唤物造成的伤害 **+50%**；
  3. 你每有 1 个存活召唤物，回合开始获得 **3** 格挡。
- 玩法循环：铺场（狼 / 熊 / 鹰 / 蛇功能各异）→ 兽群 Buff → 召唤物护卫挡刀，或献祭召唤物换爆发。
- 风险：召唤物吃 AoE 与清场；占手牌；Boss 战召唤物生存差。

#### 终职：兽化者 —— "我猎杀得太久，终于成为了野兽"

- **专属能力（不可剥夺）**「变形」：你拥有**人形 / 兽形**两种形态，每回合首次切换免费：
  - **人形**：每回合额外抽 1 牌，可使用远程 / 法术类牌；
  - **兽形**：攻击伤害 **+50%**，回合开始获得 6 格挡与 3 层荆棘。
- 实现：对接伤害管线第 3 步的 **Stance 层**；职业牌为"双模态牌"（人形 / 兽形各有效果，一套牌两种用法）。
- 与兽王的对照：**兽王靠"数量"（管理一支军队），兽化靠"形态"（管理自己的节奏）。**

## 五、法师线（法神：序秩之律）

**主题地图**：学徒白塔 → 元素裂隙 → 万法归墟（求知的三种形态：学规则 → 直面失控的规则 → 规则本身）

**核心资源**：能量（法力）、元素附着（燃 / 霜 / 雷）、魂能、诅咒

### 5.1 元素附着定义（基础）

| 附着    | 效果                                |
| ----- | --------------------------------- |
| **燃** | 每层在其回合结束造成 1 点伤害（不传染，可被反应引爆）      |
| **霜** | 每层使其攻击伤害 -1；累积到阈值时**冻结**（跳过 1 回合） |
| **雷** | 每层使其受到攻击时向其他敌人溅射，或提升所受伤害          |

### 5.2 一阶・元素师 —— "万物皆可拆成元素"

- **一阶能力（建议）**：「元素亲和」你的元素法术造成伤害时，给目标附着 1 层对应元素。

#### 终职：风暴使者 —— "当两种法则相遇，风暴就诞生了"

- **专属能力（不可剥夺）**「元素反应」：当一个敌人**同时带有两种元素**时，立即触发反应并消耗两种附着各一半：
  - **燃 + 霜 = 蒸汽爆发**：立即造成 燃层数 × 2 的伤害，其下回合伤害减半；
  - **燃 + 雷 = 超载**：对所有敌人造成 雷层数 的伤害并附着等量燃；
  - **霜 + 雷 = 超导**：附加 2 回合易伤，霜足够时立即冻结 1 回合。
- 玩法循环：交替附着 → 组合连锁 → 群体清场。考验手牌规划与出牌顺序。
- 风险：单一元素手牌会卡死；部分敌人有元素免疫 / 净化。

#### 终职：奥术圣贤 —— "未出口的咒语，正在积蓄毁天灭地"

- **专属能力（不可剥夺）**「奥术充能」：
  1. 回合结束时，每点**未使用的能量**转化为 **2 层奥术**（跨回合永久保留）；
  2. 你的法术额外造成等于奥术层数 **50%** 的伤害；
  3. 可消耗 5 层奥术，使一张法术本回合费用 -1。
- 玩法循环：Boss 放大招的回合你专注防御（不攻击 = 蓄力）→ 奥术叠厚 → 一发 X 费巨型法术逆转。
- 与风暴使者的对照：**风暴是高频连锁的组合艺术，奥术是低频巨炮的蓄力节奏。**

### 5.3 一阶・咒术师 —— "知识的禁区里，埋着最强的力量"

- **一阶能力（建议）**：「禁忌知识」你可以**消耗（Exhaust）**手牌；每回合首次消耗一张牌，抽 1 张牌。
- 系统需求：消耗区（被消耗的牌本局不再回牌堆）。

#### 终职：死灵师 —— "死亡不是终点，是另一种资源形态"

- **专属能力（不可剥夺）**「亡者为兵」：
  1. 每当一张牌被消耗，获得 1 层**魂能**；敌人死亡时获得 2 层；
  2. 魂能可代替能量支付（1 层 = 1 能量，每回合最多这样支付 2 次）；
  3. 敌人死亡时召唤 1 只骸骨兵（1 血 / 1 伤害，上限 3 只）。
- 玩法循环：用"强力但消耗"的牌 → 消耗产出魂能 → 魂能反哺施法，骸骨铺场；可配合从消耗区捞牌、亡语（死亡触发）。
- 风险：消耗不可逆，牌组越打越薄（本身是优点，但消耗牌必须有高昂代价来平衡）。

#### 终职：契约师 —— "所有人都躲开诅咒，只有我向它伸手"

- **专属能力（不可剥夺）**「以咒为薪」：
  1. 你牌组中的**诅咒牌**（无法打出、占手牌的累赘）变为可打出的**契约牌**：打出时选择「获得 6 点能量」或「造成 40 点伤害」，随后受到 **8 点生命流失**（无视格挡）；
  2. 你每向牌组加入一张诅咒牌，**永久 +1 最大生命**并回满差值。
- 玩法循环：主动通过事件 / 遗物 / 自残牌往牌组里**收集诅咒**（别人避之不及，你趋之若鹜）→ 用生命管理兑现核弹。
- 与死灵师的对照：**死灵把"消耗"变燃料，契约把"诅咒"变燃料——同为负面资源化，燃料不同。**

### 5.4 12 终职自检（全部通过"规则级"判据）

| -- | ---- | --------------------------- |

## 七、神战：毕业考试（终极 Boss）

### 7.1 统一四阶段结构

| 阶段               | 内容                                   | 考试意图       |
| ---------------- | ------------------------------------ | ---------- |
| **P1 化身**        | 神以人形 / 化身登场，使用 **Act1 Boss** 的招式     | 考基础循环      |
| **P2 代行者**       | 使用 **Act2 Boss** 的招式（军阵 / 兽群 / 元素轮替） | 考多目标与资源规划  |
| **P3 真身**        | 使用 **Act3 主题机制**（不灭 / 轮回 / 因果回放）     | 考长线适应      |
| **P4 规则对撞（半血后）** | 神**获得玩家当前终职的专属能力（神级完全体）**            | 考你对自己引擎的理解 |

### 7.2 P4 的"镜像"设计（神战的灵魂）

半血后，神把你赖以通关的能力，以更强的版本还给你：

- 你是**壁垒**？战神 P4 每回合保留 **100%** 格挡并不断重击——逼问壁垒玩家：你为输出不足准备了什么？
- 你是**盾猛**？战神获得格挡时反伤你，且格挡获取频率是你的数倍。
- 你是**嗜血者**？战神血量越低伤害越恐怖，还自带吸血——比谁先算错血线。
- 你是**契约师**？法神不断往你牌组塞诅咒（你的燃料），但每塞一张它自己也变强——燃料战，比谁先被代价压垮。
- 你是**兽王**？兽神召唤的兽群永远比你多一只。
- 你是**死灵师**？法神把你消耗掉的牌全部"招魂"回来对付你。

> 设计意图：玩家面对的是**"自己构筑的完美版"**。赢下神战不是靠数值碾压，而是靠找到自己引擎的破绽、用更精妙的出牌顺序与对策卡通关。这是三幕构筑的**终极答辩**，也在叙事上完成闭环：**你模仿神学会了规则，现在用规则杀死神。**

### 7.3 三神的 P4 专属软狂暴（DPS / 机制 check）

| 神  | P4 规则                           | 防止战斗无限拖    |
| -- | ------------------------------- | ---------- |
| 战神 | **无尽战意**：每回合叠加力量                | 软狂暴，限时输出检验 |
| 兽神 | **野性轮回**：被击倒后重生一次，形态轮替不重复       | 二阶段车轮      |
| 法神 | **因果律**：复制 / 反弹玩家的牌，每回合随机改变费用规则 | 出牌秩序全面打乱   |

> **实现要求**：12 个终职 → 12 个 P4 镜像变体。镜像逻辑必须**数据驱动**（每个终职能力配一个"神级版本"的 JobData 变体），不得硬编码进 Boss 脚本。

## 八、神性侵蚀系统

### 8.1 设计目的

STS 的局内没有一条"贯穿全局的抉择主线"。本系统让玩家在三幕中持续做一道选择题：**接受神恩（立刻变强、加速同化）还是坚守人性（奖励更薄、保住自我）。**

### 8.2 神性 / 人性的获取（建议初值）

| 事件                  | 神性变化                  |
| ------------------- | --------------------- |
| 每次转职（不可避免）          | **+20**（两次共 40）       |
| 拾取**神格遗物**          | +8 ~ +15              |
| **神坛**节点选择"接受神恩"   | +10（伴随强力即时奖励）         |
| 神坛选择"拒绝 / 砸毁"      | 神性 -5，**人性 +1**（奖励更弱） |
| 帮助叛神者 NPC、归还遗物等人性事件 | 人性 +1                 |
| 卡牌"神化"升级          | +3 ~ +5               |

### 8.3 进度条呈现

**神性与人性共用同一条进度条，双向对比：神性红色、人性蓝色。**
红色从一端增长、蓝色从另一端增长，两种颜色在同一条上此消彼长，玩家一眼即可看出"我离被同化还有多远 / 我守住了多少自我"。

**数值可行性检查（关键）**：固定 40 神性意味着凡人路线（神性 < 60）**只能再承受 ≤ 20 的额外神性**——即不拿神格遗物、拒绝神坛、谨慎接受神化牌。

> **风险提示**：凡人路线同时面对"奖励更薄 + 通关更难 + 阈值紧张"三重压力，可能在数值上不成立。**阶段 7 必须产出「神性预算表」验证**（见 §14.2）。本版暂不提供机制补偿。

### 8.4 侵蚀的效果（风险与收益对称）

- **高神性的甜头**：世界在"招安"你——商店更频繁刷神格遗物、事件给更好的奖励、神化强力牌出现率上升。
- **高神性的代价（侵蚀显化，神性 ≥ 70）**：
  - 战斗中随机出现**神谕**：强制本回合第一张牌为指定类型、某张牌费用临时改变（主题化的"困惑"）；
  - 卡牌被神化（更强但行为 / 费用被改变）；
  - **神性 ≥ 90：结局锁定为"登神"**——你已无法拒绝成为规则。
- **低神性路线（坚守人性）**：奖励更少、通关更难，但解锁**"凡人"结局**（需 人性 ≥ 3 且 神性 < 60）与专属人性遗物 / 成就。

### 8.5 对称之美

> **你无法被夺走力量（不可剥夺），你也无法退还力量（不可退还）。**
> 接受神恩前要三思——这让每一次"白送的强力奖励"都有了真实的决策重量。

| ---------- | ----------------------------------------------------------------------- |
| **普通遗物**   | 人的造物 / 自然奇物，常规被动                                                        |
| **神格遗物**   | 对应三神，强力但 **+ 神性**。**遗物全通用、跨神格不削弱**（如法师拿战神遗物玩"战法"，跨系组合是高阶构筑乐趣）；但**跨神格遗物只能通过特殊"窃权事件"获得，不进常规奖励 / 商店池**——保证不能每局都跨体系打牌，跨系构筑是偶得的惊喜而非标配 |
| **职业专属遗物** | 仅在对应转职路线出现，专门放大该职业引擎（如壁垒的"城墙砖"、契约师的"恶魔羊皮纸"）                           |

### 9.5 初始角色差异化

| 角色 | 生命 | 初始牌组（建议）                                         | 初始遗物（建议）                      |
| -- | -- | ------------------------------------------------ | ----------------------------- |
| 战士 | 30 | 5 打击 (6) + 5 防御 (5)                               | **燃烧之血**：战斗胜利后回 5 血           |
| 猎人 | 28 | 5 快斩 (5) + 4 闪避 (5) + 1 瞄准 (本回合攻击 +4)            | **兽牙护符**：每场战斗前 2 回合获得 1 层敏捷   |
| 法师 | 24 | 5 魔弹 (5) + 3 符文盾 (5) + 1 专注 (+2 能量) + 1 冷静 (抽 2) | **白塔徽记**：每回合打出第一张攻击法术后获得 3 格挡 |

## 十、技术架构设计

### 10.1 项目目录结构（第一天就定死）

```
res://

    battle/      # BattleManager, TurnFlow, IntentResolver
    pipeline/    # DamagePipeline, EffectResolver          ← 心脏
    identity/    # IdentityLayer, AbstractPower, JobData， JobDatabase  ← 心脏
    cards/       # CardData, DeckManager, CardPool
```

### 10.2 身份层（转职能力）的架构保证

"不可剥夺"最好由**架构**保证，而不是靠记得写判断：

1. `AbstractPower` 增加 `is_identity: bool = false`；身份能力 `is_turn_based` 恒为 false。
2. `Creature` 增加独立数组 `identity_powers` 与 `apply_identity_power()`；
   `DamagePipeline._sorted_powers_of()` **合并** `powers + identity_powers`（身份能力同样要进修正链）。
3. 隔离规则：
   - `remove_power()` 对身份层无效；`on_turn_end()` 不对其倒计时；
   - 战斗 `reset()` 不清身份层——**身份能力的"源头"挂在 `GameState` 的 JobData 上**，每场战斗初始化玩家 `Creature` 时重新实例化注入。任何战斗内效果（沉默 / 驱散 / 夺能）都接触不到 JobData，天然不可剥夺。

### 10.3 伤害管线（项目心脏）

统一所有伤害 / 修正的结算链。**所有终职的独特性都挂在这条链上**（盾猛接通格挡→伤害、神射手进入 `at_damage_receive`）。

必须支持的修正类型与**叠加顺序固定**：

```
基础值
 → 攻击方加成（力量、怒涛、姿态 Stance）
 → 目标减益（虚弱）
 → 目标受击加成（易伤、印记、奥术）
 → 格挡吸收
 → 结算
```

> 顺序一旦定下，**写进测试**，永不随意改动。改这里等于改全部 12 个终职。

### 10.5 Autoload 纪律

| Autoload           | 职责                        | 禁止          |
| ------------------ | ------------------------- | ----------- |
| `GameState`        | 跨场景全局状态（角色 / 幕 / 侵蚀 / 遗物） | 禁止放战斗逻辑     |
| `EventBus`         | 跨场景信号总线                   | 只放真正跨场景的事件信号 |
| `ContentRegistry`  | 卡牌 / 遗物 / 敌人 / 职业统一查询入口   | 禁止放可变状态     |

> 原则：Autoload 是服务定位器，**不是游戏逻辑的垃圾场**。任何能放进实例化场景的逻辑都不该进 Autoload。

### 10.6 数据外置原则

**禁止写死在代码里的项**：卡牌费用 / 卡牌伤害 / 格挡值 / 敌人血量 / 敌人攻击范围 / 奖励池权重 / 神性来源数值 / 遗物数值。

全部走 `.tres` Resource，代码**只读不算**。

**目标**：空 Godot 工程 → 可运行的项目骨架。**不写任何游戏逻辑。**

**产出**
- Godot 4.x 工程初始化，`project.godot` 配置完成
- 目录结构建立（见 §10.1）

**验收标准**
- [ ] 工程能打开、能运行、无报错
- [ ] 测试命令能执行且全绿（哪怕只有 1 个测试）
- [ ] `main` 分支可运行

### 阶段 1：战斗原型（薄切片）

**目标**：不追求好看，只追求**能跑**。1 个敌人 + 1 张攻击牌 + 1 张防御牌，纯数值日志。

> 本阶段代码是**一次性的**——目的是验证概念，不是沉淀资产。写完立刻进入阶段 2 重构。

**开发顺序（严格按此顺序）**
1. `Creature` 基类：生命 / 格挡 / 能量字段 + 信号
2. `Player` / `Enemy` 继承
3. `CardData`（Resource）：费用 / 类型 / 数值
4. `DeckManager`：抽牌堆 / 手牌 / 弃牌堆 + 洗牌
5. `BattleManager`：玩家回合 → 敌人回合的最小流转
6. 纯日志 UI：不画卡牌，用按钮 + 文本显示

**边界（不准越界）**
- 用**按钮点击**，不做拖拽
- 用**数值日志**，不做特效
- **1 个敌人**跑通，不做多敌人
- **不做**地图、遗物、转职、职业

**验收标准**
- [ ] 开局抽 5 张
- [ ] 出牌正确扣能量
- [ ] 回合结束弃手牌
- [ ] 敌人回合正确结算
- [ ] 抽牌堆空时正确洗牌
- [ ] 玩家 / 敌人死亡正确结束战斗

### 阶段 2：战斗系统成型

**目标**：把阶段 1 的"玩具"重构成**正式的、可长期演进的战斗内核**。全项目**最关键的阶段**。

**核心工作**

1. **伤害管线 `DamagePipeline`（第一优先）**——按 §10.3 实现修正链，顺序固定并写测试。
2. **身份层 `IdentityLayer`（第二优先）**——按 §10.2 实现"不可剥夺"的架构级隔离。
3. **意图系统 `IntentResolver`**——敌人意图（攻击 / 防御 / 增益 / 召唤）独立于敌人行为，**数据驱动**（`.tres` 配图标 + 数值）。
4. **牌堆循环**——抽 / 弃 / 洗牌；消耗区此阶段留接口（阶段 5 法师线才用）。
5. **钩子系统**——`on_turn_start` / `on_turn_end` / `at_damage_receive` / `at_damage_modify` / `on_card_played` / `on_kill` / `on_battle_start` / `on_battle_end`。

**验收标准**
- [ ] 伤害管线的**修正叠加顺序**有测试覆盖
- [ ] 身份层的**不可移除性**有测试覆盖
- [ ] 格挡结算正确
- [ ] 状态（层数 / 清零）规则正确
- [ ] 所有钩子有测试

**本阶段测试清单**

| 优先级 | 测试项 |
|---|---|
| P0 | 伤害管线修正链顺序 |
| P0 | 身份层不可剥夺性 |
| P0 | 格挡吸收计算 |
| P1 | 洗牌逻辑（空堆→重洗） |
| P1 | 能量校验（不足禁止出牌） |
| P1 | 状态层数与清零 |
| P1 | 回合开始 / 结束钩子 |

### 阶段 3：单局骨架

**目标**：把"一场战斗"扩展成"一局游戏"。**不含转职，只有一个无职业的初始角色。**

**开发顺序**
1. `MapManager`：节点生成（普通 / 精英 / 休息 / 商店 / 事件 / Boss）+ 节点移动
2. 战后奖励：三选一卡牌 + 金币
3. 商店：买卡 / 买遗物 / 删卡（遗物先留接口）
4. 事件节点：骨架 + 1~2 个占位事件
5. `RunState`：单局状态
6. `SaveManager`：单局存档 + 读档
7. 失败与重开流程

**边界**
- **不做**转职 / 职业 / 遗物实际效果（只留接口）
- **不做**侵蚀系统
- 地图敌人用占位敌人

**验收标准**
- [ ] 能从开局走到第 1 幕 Boss
- [ ] 能完成一局（打赢 Boss 或战败）
- [ ] 中途退出能读档继续
- [ ] 战败能重开新局

### 阶段 4：垂直切片 ★核心阶段★

**目标**：**用"壁垒"这一个终职，把整条管线从初始到神战 P4 全部跑通。**

> 这是整个开发路线的**转折点**。做完它，你才知道这个游戏能不能成立。

**为什么选壁垒**
- 设计最完整、机制最清晰（"回合末保留 50% 格挡"直接改写基础规则）
- **风险最高**（考验 `on_turn_end` 格挡清零规则的改写能力）
- 对手设计明确（毒 / 生命流失无视格挡 = 天敌）

**切片内容（必须全部包含）**
1. **角色**：战士（30 血 + 燃烧之血遗物）
2. **一阶**：盾卫（首张格挡 +3）
3. **终职**：壁垒（回合末保留 50% 格挡）
4. **职业牌池**：6~8 张（格挡牌、格挡转伤害、敏捷、缓冲）
5. **敌人**：
   - 2~3 个普通敌人（能测试格挡留存价值）
   - 1 个精英（高单发伤害，逼玩家叠甲）
   - 1 个设计上**克制壁垒**的敌人（毒或生命流失）——**必须存在**，验证"弱点机制"
6. **Boss**：竞技场·卡冈（盾 / 狂双姿态，战斗中预览盾卫 / 狂战分支）
7. **转职 UI**：从盾卫转壁垒的完整流程
8. **神战 P4 雏形**：战神保留 **100%** 格挡 + 每回合力量增长（壁垒的镜像）

**这一阶段的真正目的**：暴露所有"设计上需要但尚未验证"的钩子。

**验收标准**
- [ ] 从选角到"打赢 P4 战神"，全程可玩，无崩溃、无僵局
- [ ] 壁垒的格挡留存规则在**所有**回合结束场景正确（含中毒、眩晕、Boss 特殊回合）
- [ ] 克制壁垒的敌人在"未准备对策"时确实构成威胁
- [ ] 数值手感成立：普通战斗 3~5 回合，Boss 8~15 回合
- [ ] 全流程测试全绿

**决策点**：手感成立 → 放心横向扩展；手感不成立 → **先修架构，再扩展**，绝不带病扩展。

### 阶段 5：系统横向扩展

**目标**：按切片验证过的模板，复制到其他系统。**顺序经过刻意设计。**

| 序 | 系统 | 理由 |
|---|---|---|
| 1 | **遗物系统** | 所有终职的公共依赖，钩子已在阶段 2 预留，风险最低，收益最大 |
| 2 | **法师线** | 元素反应 / 奥术蓄力是纯资源管线，**不依赖任何新实体系统** |
| 3 | **猎人线** | 召唤兽 / 形态需要新增 `allies` 系统 + 敌人 AI 目标选择 + 友方 UI，**风险最高，放最后** |

> **顺序说明**：猎人线的"友方单位"是**全项目唯一新增的实体类别**（其他都是钩子或资源字段），应放在架构最成熟时做。故 **法师线先于猎人线**。

**每个系统的开发模板（复用壁垒切片经验）**
```
1. 定义数据（Resource 类 + .tres 配置）
2. 实现机制钩子（挂到已有管线上）
3. 写测试（管线交互 + 边界）
4. 做内容（卡牌 / 敌人 / 遗物）
5. 端到端验证（用切片流程回归）
6. 调数值到手感成立
```

**5.1 遗物系统**
- `AbstractRelic`：`at_damage_modify / on_use_card / at_battle_start / on_turn_start/end`
- 三层分类：普通 / 神格（+神性）/ 职业专属
- `RelicFactory` + 内容注册
- 跨神格遗物仅通过"窃权事件"获得（不进常规池）

**5.2 法师线**
- 元素附着（燃 / 霜 / 雷）+ 反应（蒸汽 / 超载 / 超导）
- 奥术蓄力（溢出能量 → 奥术层数）
- 消耗区（Exhaust）
- 诅咒契约（诅咒牌变可打出）
- 一阶：元素师 / 咒术师；终职：风暴使者 / 奥术圣贤 / 死灵师 / 契约师

**5.3 猎人线**
- `Creature.allies` + 友方回合处理 + Boss / AI 目标选择
- 印记系统 + 满层引爆
- 形态 Stance（人形 / 兽形）
- 一阶：游侠 / 驯兽师；终职：神射手 / 风行者 / 兽王 / 兽化者

**验收标准**
- [ ] 每条线做完后，**回归壁垒切片全流程**，确保没打破已有机制
- [ ] 每个新机制的管线交互有测试
- [ ] 12 个终职全部可玩，且每个都通过"规则级"自检（改写 / 接通 / 反转，非纯数值）

### 阶段 6：内容与主题化

**目标**：把系统变成"有血有肉的游戏"。

**工作内容**
1. **九张地图主题化**（§6）
   - 战士：竞技场 / 战场 / 古战场
   - 猎人：翠林猎场 / 大荒野 / 万兽冢
   - 法师：学徒白塔 / 元素裂隙 / 万法归墟
   - 每图 = 环境机制（ActModifier）+ 特色敌人池 + 考官 Boss
2. **三神战四阶段**（§7）
   - P4 **数据驱动**：每个终职配一个"神级版本"的 JobData 变体，不硬编码
   - 三神专属软狂暴：战神（无尽战意）/ 兽神（野性轮回）/ 法神（因果律）
3. **侵蚀系统**（§8）
   - 神性 / 人性共用一条进度条（红左蓝右）
   - 神性 ≥ 70 显化；≥ 90 锁定"登神"
   - **凡人结局**：人性 ≥ 3 且 神性 < 60（**仅实现结局判定，不做机制补偿**）
4. **节点类型扩展**：神坛 / 转职仪式 / 叛神者
5. **药水扩展**：神血 / 兽性药剂 / 忘川水 / 法力涌泉
6. **特殊牌**：神化牌 / 考题牌 / 神谕牌 / 契约牌

**验收标准**
- [ ] 三角色各有完整的从开局到结局的体验
- [ ] 三结局均可触发
- [ ] 九个 Boss 各有独特机制，不是数值堆料
- [ ] 神战 P4 的 12 个镜像变体全部实现

### 阶段 7：平衡与元进度

**目标**：从"能通关"到"耐玩"。

**平衡顺序（严格）**
1. **先让游戏能赢**——敌人强度降到"正常玩就能过"
2. **再避免随便赢**——加入"只出攻击牌就会死"的压力
3. **再处理过强套路**——壁垒无限叠甲 / 鏖战者无限连击 / 奥术无限蓄力
4. **最后雕细节体验**——动画时长、音效、过牌手感

**元进度**
- 三结局计数与成就
- 卡牌 / 遗物解锁（按局内遭遇逐步解锁）
- **进阶等级**（Ascension 式难度递增，每级加一条规则）
- 每日种子 / 排行榜（可选）

**验收标准**
- [ ] 无"必胜套路"与"必败开局"
- [ ] 每个终职都有可玩的构筑方向
- [ ] 神性预算表验证通过（凡人路线数值成立）
- [ ] 完成 1 轮完整 playtest 记录

### 阶段 8：收尾

**目标**：从"能玩"到"能交出去"。

**工作内容**
1. **性能优化**
   - 用 Profiler 定位 GDScript 热点
   - 必要时对高频结算（伤害管线）做对象池 / 缓存
   - UI 重绘优化（避免每帧重建卡牌列表）
2. **稳定性**
   - 全流程 10 局无崩溃压测
   - 存档兼容性测试（跨版本读档）

3. **体验打磨**

4. **发布准备**

5. **文档交付**

## 十二、日常开发流程与工程规范

### 12.1 单个功能的完整流程

```
1. 建任务卡 → 写清目标 / 范围 / 完成标准
2. 从 main 拉分支 → feature/xxx 或 fix/xxx 或 refactor/xxx
3. 只写与本目标直接相关的代码
4. 本地运行 + 跑测试
5. commit（写清"为什么"）
6. 推送 → 建 PR
7. 自查 → 合并回 main
8. 回归：跑一遍切片流程关键路径
```

### 12.2 任务卡粒度规则（硬性）

> **一张任务卡 = 一次 commit = 一个可独立测试的行为。**

- 好粒度：`加基础状态系统`、`加敌人意图显示`、`加战后选牌界面`
- 坏粒度：`完成整个战斗系统`、`完成所有地图系统`
- **判定法**：如果一张卡需要用"和"连接两件事 → 拆成两张。

### 12.3 分支规范

| 前缀 | 用途 |
|---|---|
| `main` | 永远可运行 |
| `feature/xxx` | 新功能 |
| `fix/xxx` | 修 Bug |
| `refactor/xxx` | 重构（不改行为） |
| `test/xxx` | 纯测试 |
| `content/xxx` | 纯内容（卡牌 / 敌人 / 数值） |

### 12.4 提交信息（按"系统"而非"文件"组织）

```
feat(identity): 增加不可剥夺身份层与 JobData 注入
feat(pipeline): 将身份能力并入伤害修正链
feat(job): 增加壁垒回合末格挡留存规则钩子
fix(deck): 抽牌堆空时禁止在结算中途触发洗牌
test(identity): 验证 remove_power 对身份层无效
content(cards): 增加盾卫 6 张职业牌初值
```

> 规范要点：写"**为什么**"和"**防御了什么失效模式**"，而不是"改了什么文件"。
> 例如：`fix: guard card play when energy < cost to prevent negative energy state`

### 12.5 每次改动的必测项

- 开局正常抽牌
- 出牌正确扣能量
- 回合结束弃牌
- 敌人回合正常结算
- 抽牌堆空时正常洗牌
- 玩家 / 敌人死亡正确结束战斗

### 12.6 资源文件格式规范

- `.tscn` / `.tres` **不使用手写 UID**，交给引擎生成
- `.tscn` 中**不写注释**（Godot 解析器不支持）
- 每个 `.tscn` 以 `[gd_scene load_steps=N format=3]` 开头；每个 `.tres` 以 `[gd_resource type="..." format=3]` 开头
- **优先在 Godot 编辑器内创建** Resource / Scene，代码只在必要时生成

## 十三、测试策略

### 13.1 测试优先级（不是全覆盖，是覆盖"高价值逻辑"）

| 批次 | 时机 | 测试项 |
|---|---|---|
| **第一批**（写代码时就写） | 阶段 2 | 伤害管线修正链顺序 / **身份层不可剥夺性** / 格挡结算 / 印记乘法修正 |
| **第二批**（系统成型后） | 阶段 2~3 | 洗牌逻辑 / 能量校验 / 状态叠加 / 回合钩子 |
| **第三批**（内容填充后） | 阶段 5~6 | 奖励生成 / 转职流程 / 地图生成 |

### 13.2 全项目最该守住的三个测试

1. **身份层不可移除性**——`remove_power` 无效、`reset` 不清、沉默无效、跨战斗重新注入。**这是架构核心承诺。**
2. **伤害管线修正链顺序**——叠加顺序一旦错，所有终职数值全错。
3. **格挡留存规则（壁垒）**——跨回合改写基础规则，涉及所有回合末场景。

### 13.3 测试纪律

- 测试与功能同 PR 提交
- 每次合并 `main` 前，**切片关键路径必须全绿**
- 测试失败不跳过，不带病合并

## 十四、数值与调优流程

### 14.1 数据外置

见 §10.6——所有数值走 `.tres`，代码只读不算。

### 14.2 必须建立的三个调优指标

| 指标 | 定义 | 健康区间 |
|---|---|---|
| **引擎启动回合** | 终职引擎开始滚雪球的回合数 | ≤ 5，否则普通战斗里是废的 |
| **P4 镜像挫败率** | 玩家首次遇到 P4 的胜率 | 首次应必输，第二次能找到破绽 |
| **神性预算表** | 凡人路线全三幕能承受的额外神性 | 现在只有 20，需验证是否可行 |

### 14.3 每轮 playtest 记录项

- 平均战斗回合数（分普通 / 精英 / Boss）
- 第几层最容易死（死亡层数分布）
- 哪张卡明显过强
- 哪种开局最容易滚雪球
- 某个敌人是否"恶心但不有趣"
- 各终职的引擎启动回合
- 神战 P4 的镜像挫败率
- 凡人路线的神性预算是否超支

### 14.4 调优顺序（严格）

1. 先让游戏**能赢**
2. 再避免**随便赢**
3. 再处理**某些套路过强**
4. 最后雕**细节体验**
