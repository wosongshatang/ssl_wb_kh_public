# 遗物图标（44 张）

**用途**：遗物查看弹层 / 商店 / 结算
**尺寸**：256×256 · `transparent` · `quality=high`
**显示尺寸**：约 36px（所以必须「一个符号 + 强剪影」）

**命名**：文件名 = 下面列表里的 id，放进本目录即生效（不用改任何 `.tres`）。
**缺图行为**：回退到程序化几何图形 / 占位方块，**不会崩**——所以可以分批投。

## 提示词拼接方式

```
共用基底 + 明度基调 + D 类图标专属基底 + 主体短语
```

完整提示词见 `docs/art_asset_requirements.md`。
