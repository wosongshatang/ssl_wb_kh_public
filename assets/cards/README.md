# 卡图目录（阶段 8）

## 约定

**文件名 = 卡牌 id**，丢进来就生效，**不用改任何 `.tres`**：

```
assets/cards/strike.png   →  卡牌 strike（打击）
assets/cards/defend.png   →  卡牌 defend（防御）
```

卡牌 id 见 `data/cards/*.tres` 的**文件名**。

## 尺寸

| 项 | 值 |
|---|---|
| 卡面整体 | 118 × 166 |
| **图区** | **约 104 × 113（接近方形）** |
| 建议出图 | **512×512 或 1024×1024 方形**，游戏内等比铺满后裁切 |

⚠️ **卡图 ≠ 立绘**。立绘是 168×128 横向，卡图是方形。
**竖版人物立绘塞进方形卡图会只剩一截躯干**——两者必须分开出图。

## 升级牌共用基础卡的图

`strike+`（升级版打击）**沿用** `strike.png`。
不要为升级牌另出图——`ContentRegistry.get_card_art()` 会自动剥掉 `+` 后缀。

## 缺图会怎样

**不会崩，只是回退到几何图形**（攻击=斜刃 / 技能=盾牌 / 能力=菱形）。
所以可以**分批出图**：先做常用的 20 张，其余继续用几何占位，两者并存不冲突。

## ⚠️ 必须用节点渲染，不要用 `_draw()` 画贴图

见 `docs/decisions.md` **D35**：`_draw()` 里 `draw_texture_rect*` 画大图
在 BattleScene 里会渲染成**纯白块**（孤立场景却正常，极具误导性）。
卡图走的是 `CardView._art_texture`（`TextureRect` 节点）。
